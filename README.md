# Email Worker: Supplier Information Collector

Automated system for gathering and structuring data from service providers via email.

## 🤖 Purpose
When a travel agency searches for new partners (hotels, transport, guides), this bot automates the initial communication. It parses incoming emails and collects necessary data into a structured format, reducing manual work for managers.

## ⚙️ Key Features
* **Automated Parsing:** Extracts specific details from supplier emails.
* **Data Structuring:** Converts messy email text into organized data.
* **Gmail/SMTP Integration:** Connects directly to the corporate mailbox.

## 🛠 Tech Stack
* **Python**
* **IMAP/SMTP libraries**
* **Regular Expressions (Regex)** for data extraction.
